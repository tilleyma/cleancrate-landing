The sensible questions

Control stays with the DJ.

Does it change my library automatically?

No. The workflow starts read-only, produces a reviewable change set and applies only approved changes after a backup.

What happens when a genre is ambiguous?

Ambiguous cases stay visible for human review. The aim is a useful library taxonomy, not false precision.

Are the playlists fixed templates?

The useful version combines the vocabulary already present in the collection — such as style, era, situation and vocals — so playlist ideas can match how the DJ prepares and plays.

Is the product available now?

It is at the product-definition stage. This page is helping decide which capabilities deserve the first release.
